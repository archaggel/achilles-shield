# 🛡️ Achilles' Shield

**AI Security & Safety Agent**

Codename: **ASPIS**

Achilles' Shield is an educational and research project exploring
the use of AI agents in cybersecurity, with particular emphasis
on secure agent design, human oversight, and AI safety.

## Current Status

🚧 Early Development — v0.1

## Initial Goals

- Analyze cybersecurity events
- Explain potential threats
- Recommend defensive actions
- Maintain human control over security-sensitive actions

## Core Principle

> Observe. Analyze. Protect. Never act beyond authority.
